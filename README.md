FOOD RESCUE - INTELLIGENT SURPLUS FOOD REDISTRIBUTION

Introduction

FoodRescue is a console based application written in java which assists n managing the surplus food donations nd distribution of the foods to the receivers depending on their food requirements and emergency situations.

The system enables donors to provide information about surplus food , enables the receivers to make food requests, automatically generates food matchingof food items and allocation of food for suitable matching.

Features

Add Food Donations
Add Food Requests
View Available Food Items
View Pending Food Requests
Smart Food Matching and Allocation
View Allocation History
Identify Urgent Food Items
View System Statics
Sava Allocation History to a File
View Saved Allocation History
Input Validation and Error Handling
